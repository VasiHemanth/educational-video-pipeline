# Azure Domain Reference

## Core Services for Video Content

### Compute
- Azure Functions (FaaS), AKS (managed K8s), Container Apps (serverless containers), VMs, App Service

### Data & Analytics
- Synapse Analytics (warehouse), Stream Analytics, Data Factory (ETL), Databricks, Event Hubs (streaming), Service Bus (messaging)

### Storage
- Blob Storage, Cosmos DB (multi-model NoSQL), Azure SQL, Azure Cache for Redis, Table Storage

### AI/ML
- Azure OpenAI Service, Azure ML, Cognitive Services, AI Search, Azure AI Studio, Semantic Kernel

### Networking & Security
- Front Door (CDN + WAF), Application Gateway, Azure Firewall, VNet, Azure AD (Entra ID), Key Vault, Managed Identity

### DevOps
- Azure DevOps, GitHub Actions, Azure Monitor, Application Insights, Log Analytics, Azure Policy, Bicep/ARM
