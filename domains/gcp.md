# GCP Domain Reference

## Core Services for Video Content

### Compute
- Cloud Run (serverless containers), Cloud Functions (FaaS), GKE (managed K8s), Compute Engine (VMs), App Engine

### Data & Analytics
- BigQuery (warehouse), Dataflow (stream/batch), Dataproc (Spark/Hadoop), Pub/Sub (messaging), Cloud Composer (Airflow)

### Storage
- Cloud Storage (GCS), Firestore (NoSQL), Cloud SQL (managed Postgres/MySQL), Spanner (global relational), Bigtable (wide-column), Memorystore (Redis/Memcached)

### AI/ML
- Vertex AI (ML platform), Gemini API, AutoML, Vertex AI Agent Engine (agentic), Model Garden, Feature Store

### Networking & Security
- Cloud Load Balancing, Cloud CDN, Cloud Armor (WAF), VPC, Cloud NAT, Identity-Aware Proxy, Cloud KMS

### DevOps
- Cloud Build, Artifact Registry, Cloud Deploy, Cloud Monitoring, Cloud Logging, Cloud Trace, Error Reporting
