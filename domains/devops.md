# DevOps Domain Reference

## Core Concepts for Video Content

### CI/CD
- Pipeline design, Build caching, Artifact management, Deployment strategies (blue-green, canary, rolling), Feature flags

### Observability
- Metrics (Prometheus, Datadog), Logs (ELK, Loki), Traces (Jaeger, Tempo), SLOs/SLIs/SLAs, Alerting, Dashboards

### GitOps
- ArgoCD, Flux, Pull-based deployment, Drift detection, Multi-cluster management, Progressive delivery

### Container Security
- Image scanning, Supply chain security (SLSA), Sigstore, Admission controllers, Runtime security (Falco), SBOM

### SRE Practices
- Error budgets, Toil reduction, Incident management, Postmortems, Chaos engineering, On-call practices

### Infrastructure as Code
- Terraform, Pulumi, CDK, Crossplane, Policy-as-code (OPA, Sentinel), GitOps for IaC
